# Cinemood | تشخیص احساسات چهره و پیشنهاد فیلم با هوش مصنوعی

## معرفی پروژه

**Cinemood** یک پروژه هوش مصنوعی است که با استفاده از یادگیری عمیق و شبکه عصبی کانولوشنی (CNN)، احساسات افراد را از روی تصاویر چهره تشخیص می‌دهد و بر اساس احساس شناسایی‌شده، فیلم‌هایی متناسب با آن پیشنهاد می‌کند.

این پروژه با هدف به‌کارگیری عملی هوش مصنوعی در تحلیل حالات چهره و ارائه پیشنهادهای فیلم طراحی شده است.

مدل تشخیص احساسات با استفاده از مجموعه‌داده FER-2013 آموزش داده شده است. همچنین، برنامه دارای رابط کاربری تعاملی است تا کاربران بتوانند به‌آسانی از قابلیت‌های آن استفاده کنند.

## اهداف پروژه

- پیاده‌سازی مدل یادگیری عمیق برای تشخیص احساسات چهره.
- استفاده از شبکه عصبی کانولوشنی (CNN) برای طبقه‌بندی احساسات.
- تشخیص زنده احساسات از طریق وب‌کم.
- نمایش احساس پیش‌بینی‌شده توسط مدل.
- پیشنهاد فیلم بر اساس احساس شناسایی‌شده.
- ایجاد رابط کاربری با استفاده از Gradio.
- استفاده مجدد از مدل آموزش‌دیده بدون نیاز به آموزش مجدد در هر بار اجرای برنامه.

## فناوری‌های استفاده‌شده

- **Python:** زبان برنامه‌نویسی اصلی پروژه.
- **TensorFlow و Keras:** برای پیاده‌سازی و اجرای مدل یادگیری عمیق.
- **CNN (Convolutional Neural Network):** برای استخراج ویژگی‌های تصاویر چهره و طبقه‌بندی احساسات.
- **FER-2013:** مجموعه‌داده مورد استفاده برای آموزش و ارزیابی مدل.
- **Gradio:** برای ایجاد رابط کاربری تعاملی.
- **NumPy و OpenCV:** برای پردازش تصاویر و محاسبات موردنیاز، در صورت استفاده در کد پروژه.

## قابلیت اصلی: تشخیص احساسات چهره

مدل CNN پروژه برای شناسایی پنج حالت احساسی آموزش داده شده است:

| نام انگلیسی | معادل فارسی |
|---|---|
| Angry | عصبانی |
| Happy | خوشحال |
| Neutral | خنثی |
| Sad | غمگین |
| Surprise | متعجب |

پس از دریافت تصویر چهره، مدل آن را پردازش کرده و احساس پیش‌بینی‌شده را نمایش می‌دهد.

## قابلیت‌های امتیازی پروژه

### ۱. تشخیص زنده احساسات از طریق وب‌کم

یکی از قابلیت‌های امتیازی پروژه، تشخیص زنده احساسات چهره با استفاده از وب‌کم است.

کاربر می‌تواند وب‌کم را از طریق رابط کاربری فعال کند تا سیستم تصاویر دریافتی را پردازش کرده و احساس چهره را تشخیص دهد.

**مراحل عملکرد:**

1. فعال‌سازی وب‌کم از طریق رابط کاربری.
2. دریافت تصاویر چهره به‌صورت زنده.
3. پردازش تصاویر با استفاده از مدل آموزش‌دیده CNN.
4. پیش‌بینی احساس چهره.
5. نمایش نتیجه در رابط کاربری.

برای جلوگیری از تغییرات غیرضروری در نمایشگرها، برنامه می‌تواند نتایج را تنها هنگام تغییر احساس پیش‌بینی‌شده به‌روزرسانی کند.

### ۲. پیشنهاد فیلم بر اساس احساس تشخیص‌داده‌شده

قابلیت امتیازی دیگر پروژه، پیشنهاد فیلم متناسب با احساس شناسایی‌شده کاربر است.

پس از تشخیص احساس، برنامه اطلاعات فیلم‌های موجود را بررسی می‌کند و فیلم‌های متناسب با احساس پیش‌بینی‌شده را به کاربر پیشنهاد می‌دهد.

**مراحل عملکرد:**

1. دریافت تصویر از کاربر یا وب‌کم.
2. تشخیص احساس با استفاده از مدل CNN.
3. دریافت برچسب احساس پیش‌بینی‌شده.
4. بررسی اطلاعات فیلم‌های موجود.
5. نمایش فیلم‌های پیشنهادی.

این قابلیت، مدل تشخیص احساسات را به یک کاربرد عملی در حوزه سرگرمی تبدیل می‌کند.

## نتایج ارزیابی مدل

مدل تشخیص احساسات روی مجموعه‌داده آزمایشی شامل **۳۰۲۲ نمونه** ارزیابی شده است.

### دقت کلی مدل

**دقت روی داده‌های آزمایشی (Test Accuracy): ۷۱٫۰۱٪**

این مقدار نشان می‌دهد که مدل در حدود ۷۱ درصد از نمونه‌های مجموعه آزمایشی، احساس را به‌درستی طبقه‌بندی کرده است.

### گزارش عملکرد مدل

| احساس | Precision | Recall | F1-score | تعداد نمونه |
|---|---:|---:|---:|---:|
| عصبانی (Angry) | 0.6319 | 0.5988 | 0.6149 | 496 |
| خوشحال (Happy) | 0.8643 | 0.8498 | 0.8570 | 899 |
| خنثی (Neutral) | 0.5942 | 0.6661 | 0.6281 | 620 |
| غمگین (Sad) | 0.5987 | 0.5898 | 0.5942 | 607 |
| متعجب (Surprise) | 0.8373 | 0.7850 | 0.8103 | 400 |
| **میانگین کل (Macro Avg)** | **0.7053** | **0.6979** | **0.7009** | **3022** |
| **میانگین وزنی (Weighted Avg)** | **0.7138** | **0.7101** | **0.7113** | **3022** |

### تحلیل نتایج

بر اساس نتایج ارزیابی:

- **احساس خوشحالی:** مدل با F1-score برابر با 0.8570 بهترین عملکرد را در میان پنج کلاس داشته است.
- **احساس تعجب:** مدل با F1-score برابر با 0.8103 عملکرد مناسبی در تشخیص این کلاس نشان داده است.
- **احساس خنثی:** مدل در شناسایی این حالت عملکرد متوسطی دارد.
- **احساس عصبانیت و غمگینی:** این دو کلاس نسبت به خوشحالی و تعجب چالش‌برانگیزتر بوده‌اند.

این نتایج نشان می‌دهند که عملکرد مدل در تمام کلاس‌های احساسی یکسان نیست و امکان بهبود تشخیص برخی احساسات وجود دارد.

### ماتریس درهم‌ریختگی (Confusion Matrix)

ماتریس درهم‌ریختگی برای بررسی عملکرد مدل در هر کلاس و مشاهده موارد تشخیص درست و اشتباه استفاده شده است.

این ماتریس نشان می‌دهد که مدل در تشخیص برخی حالات، مانند خوشحالی، عملکرد بهتری دارد؛ درحالی‌که بین بعضی حالات دیگر، مانند خنثی و غمگین، اشتباهاتی رخ می‌دهد.

## راهنمای نصب و اجرای پروژه

برای استفاده از برنامه، نیازی به آموزش مجدد مدل نیست؛ کافی است فایل مدل آموزش‌دیده و سایر فایل‌های موردنیاز پروژه در دسترس باشند.

### مرحله اول: دریافت پروژه

مخزن پروژه را از گیت‌هاب دریافت کنید:

```bash
git clone https://github.com/Hadiskheiri2009/Cinemood.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd Cinemood
```

### مرحله دوم: نصب کتابخانه‌های موردنیاز

ابتدا مطمئن شوید Python روی سیستم نصب شده است.

سپس دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

### مرحله سوم: اجرای برنامه

فایل اصلی برنامه، یعنی `app.py`، را اجرا کنید:

```bash
python app.py
```

پس از اجرای برنامه، Gradio یک آدرس محلی برای دسترسی به رابط کاربری نمایش می‌دهد.

### مرحله چهارم: باز کردن برنامه در مرورگر

در خروجی ترمینال، آدرس محلی زیر را پیدا کنید:

**http://127.0.0.1:7860**

این آدرس را کپی کرده و در نوار آدرس مرورگر خود وارد کنید.

با باز شدن صفحه، رابط کاربری Cinemood نمایش داده می‌شود و می‌توانید با قابلیت‌های برنامه تعامل داشته باشید.

**نکته مهم:** ابتدا باید برنامه را در ترمینال اجرا کنید و تا زمانی که می‌خواهید از آن استفاده کنید، فرایند اجرای برنامه باز بماند. آدرس `127.0.0.1` به همان رایانه‌ای اشاره می‌کند که برنامه روی آن اجرا شده است؛ بنابراین این آدرس به‌تنهایی برای دسترسی داوران از راه دور مناسب نیست.

### مرحله پنجم: استفاده از برنامه

پس از باز شدن رابط کاربری:

1. تصویر چهره را وارد کنید یا وب‌کم را فعال کنید.
2. منتظر بمانید تا مدل احساس را تشخیص دهد.
3. نتیجه تشخیص احساس را مشاهده کنید.
4. پیشنهادهای فیلم را بررسی کنید.

## ساختار پروژه

ساختار زیر نمونه‌ای از فایل‌های موردنیاز پروژه است و باید با نام فایل‌های واقعی مخزن هماهنگ شود:

```text
Cinemood/
│
├── app.py
├── sinemood_cnn.keras
├── 01_explore.ipynb
├── requirements.txt
└── README.md
```

- `app.py`: برنامه اصلی و رابط کاربری.
- `sinemood_cnn.keras`: مدل آموزش‌دیده تشخیص احساسات، در صورت مطابقت با نام واقعی فایل.
- `01_explore.ipynb`: دفترچه بررسی داده‌ها و ارزیابی مدل.
- `requirements.txt`: فهرست وابستگی‌های موردنیاز.
- `README.md`: مستندات پروژه.

اگر پروژه به فایل‌های دیگری، مانند اطلاعات فیلم‌ها، نیاز دارد، آن فایل‌ها نیز باید در ساختار نهایی معرفی شوند.
